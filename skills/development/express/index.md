# Express.js Skills

## Versions

- [v5](./v5/index.md) - For Express.js v5+ projects (current `portal-api` standard).

## Auth Mode Selection

- For frontend pairing, use the global matrix in `../context.md`.
- Express + Next web apps typically map to JWT/Bearer mode (`express/v5/auth` + `nextjs/v16/auth-jwt`).

## Organization Contract

Each Express subskill in `v5` is folderized and assignable through its own `SKILL.md`.
Expected layout:

- `<subskill>/SKILL.md`
- `<subskill>/assets/*`
- `<subskill>/references/*`
- `<subskill>/scripts/*`
