# Next.js Skills

## Versions

- [v16](./v16/index.md) - For Next.js 16+ projects using App Router, Tailwind v4, and React 19.

## Auth Mode Selection

- Before choosing an auth subskill, check the global matrix in `../context.md`.
- For token-first APIs (Express), prefer `nextjs/v16/auth-jwt/SKILL.md`.
- For Laravel SPA web auth, prefer `nextjs/v16/auth/SKILL.md`.

## Organization Contract

Each v16 subskill is folderized and assignable through its own `SKILL.md`.
Expected layout:

- `<subskill>/SKILL.md`
- `<subskill>/assets/*`
- `<subskill>/references/*`
- `<subskill>/scripts/*`
