## Weekly Marketing Standup Agenda

**Duration:** 30 minutes
**Attendees:** All team + CEO
**Day:** Monday morning

```
1. Metrics Review (TM4) - 5 min
   • Last week's numbers vs. targets
   • Alerts or concerns

2. Content Status (TM1) - 5 min
   • Published last week
   • Planned this week
   • Blockers

3. Leads & Pipeline (TM2) - 5 min
   • New leads
   • MQL/SQL movement
   • Follow-up status

4. Events & Partners (TM3) - 5 min
   • Upcoming events
   • Partner activities
   • Logistics needs

5. CEO Updates - 5 min
   • Strategic priorities
   • Key meetings/opportunities
   • Decisions needed

6. This Week's Priorities - 5 min
   • Top 3 priorities per person
   • Dependencies and handoffs
```

## Quality Gates

### Gate 1: Strategy Approval
Before any campaign begins:
- [ ] Objective clearly defined
- [ ] Target audience specified
- [ ] Budget allocated
- [ ] Success metrics set
- [ ] CEO sign-off obtained

### Gate 2: Content Ready
Before launch:
- [ ] All content created
- [ ] Internal review completed
- [ ] Legal/compliance checked (if needed)
- [ ] Technical setup verified
- [ ] Team briefed

### Gate 3: Launch Authorization
Before going live:
- [ ] Tracking confirmed working
- [ ] Team knows their roles
- [ ] Escalation paths clear
- [ ] Rollback plan exists

### Gate 4: Optimization Review
After Week 1:
- [ ] Performance data analyzed
- [ ] Winning/losing elements identified
- [ ] Adjustments made
- [ ] Continue/pivot/stop decision made
